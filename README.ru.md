# Код проекта: экспрессия генов и масса тела

Здесь собраны и упорядочены **существующие** скрипты проекта. Новый анализ, новый статистический модуль и новая система воспроизведения не добавлялись. Сохранены исходные имена, нумерация, методы, фильтры, параметры и seed.

Начните с [карты анализов](docs/analysis-map.md). В ней показана фактическая цепочка работы: измерения CAGE → восстановление и переаннотирование генов → фиксированные и уточнённые группы → сопоставление с массой → коэкспрессия и общие регуляторные кандидаты. Млекопитающие представлены отдельными ветвями анализа карт, WGCNA и pySCENIC.

В каждой ветви есть README с назначением скриптов, порядком шагов, входами и выходами. Взаимозависимые файлы оставлены рядом: переносить их по одному в разные папки означало бы сломать импорты и относительные пути.

При сборке удалены только привязки к конкретным домашним каталогам: вместо них стоят явные `/path/to/…`. Алгоритмы не переписывались. Контрольные суммы исходных файлов и подготовленных копий приведены в `provenance/source_manifest.json`. Все расчёты заново не запускались; выполнена проверка целостности, состава и синтаксиса.

Крупные исходные данные и живые исследовательские рабочие папки остаются у авторов. В репозиторий вошли код и выбранные сохранённые численные входы постера; редактура Figma, личная фотография, QR и десятки промежуточных PDF сюда не входят.
