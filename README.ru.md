# Код и результаты проекта

Репозиторий охватывает работу шире постера: птичьи измерения и девять генных групп, поиск по тысячам функциональных карт в трёх панелях млекопитающих, коэкспрессию, промоторные мотивы и три запуска pySCENIC. [Обзор результатов](docs/results.md) ведёт к таблицам и рисункам, включая отрицательные проверки и зависимость результатов от модели.

**По сохранённым данным можно повторить часть расчётов и рисунки. Полное воспроизведение исследования от исходных прочтений пока не обеспечено.** Это разные уровни: повторная отрисовка, пересчёт по замороженным измерениям и повторное получение самих измерений/сетей.

Для проверок и Python-рисунков из чистого исходного checkout:

```bash
python3.11 -m venv .venv
. .venv/bin/activate
python -m pip install -r environments/replay-requirements.txt
python -m bodymass --verify-data
python -m unittest discover -s tests -v
python -m bodymass figures all-maps --out results/all_maps
python -m bodymass figures refine-motifs --out results/motifs
```

Есть отдельные R-команды для пересчёта 123 корреляций сохранённых модулей и построения рисунков ERG/FOXP4 и их мишеней. Они читают включённые в репозиторий таблицы. [Инструкция по воспроизведению](docs/reproducibility.md) описывает зависимости, точную область проверок и недостающие внешние входы.

Код остаётся в пяти научных модулях: `avian`, `groups`, `networks`, `scenic`, `figures`. Общий вход — `python -m bodymass --list`. Новых научных алгоритмов при упаковке не добавлено. Предыдущие 164 скрипта сохранены в истории Git; не все исторические разведочные варианты являются текущими этапами запуска.
