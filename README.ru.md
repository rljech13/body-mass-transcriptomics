# Код проекта: пять связных блоков

Вместо большого списка атомарных файлов основной код сведён в пять научных модулей: **птицы, генные группы, коэкспрессия, pySCENIC и фигуры**. Общий вход:

```bash
python -m bodymass --list
```

Расчётные тела существующих процедур находятся внутри модулей. Старые Python-файлы не запускаются через `exec`, `runpy` или диспетчер подпроцессов. Пути вынесены в конфигурацию; импорт пакета и просмотр плана не запускают расчёты.

```bash
cp config/example.json config/local.json
# Указать свои пути в config/local.json
python -m bodymass avian cage --config config/local.json --plan
```

`--plan` показывает выбранный шаг. Для выполнения он убирается. Параметры конкретного шага, например `--seed 20261023`, передаются исходному разбору аргументов. Методы, численные параметры, фильтры и статистические поправки сохранены.

История прежних скриптов осталась в Git, в коммите `d230e56`. В рабочем дереве её нет. Для каждого включённого расчёта сохранена связь с исходным файлом и SHA-256. Подробности — в [карте рабочих процессов](docs/workflows.md).

Проверены сохранение результатов исходных функций на 18 фиксированных ассоциациях, интерфейс GRN и отсутствие расчётов при просмотре плана. Полные биологические анализы при рефакторинге не перезапускались.
