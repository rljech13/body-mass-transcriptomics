# Карта анализов / analysis map

## 1. Птицы: от измерений к группам

Папка: `analyses/avian/`. Исходная нумерация отражает историю исследования. Это несколько ветвей и диагностик, а не один скрипт, который следует безусловно запустить от 01 до 98.

| Этап | Исходные скрипты | Вход → результат |
|---|---|---|
| Исходная постановка и первые сопоставления | 01–16, включая 08/08b и 14–16 | Первичные матрицы, аннотации и массы → первые OXPHOS/метаболические сопоставления и проверки интерпретации |
| Пересопоставление CAGE и диагностики | 17–28 | Геномы, CAGE и исходные положения генов → перерасчёт сигнала, проверки нулей, покрытия и случайных наборов |
| Сопоставление с другими источниками | 29–44 | Матрицы коллег и независимые RNA-панели → сравнение одинаковых метрик и списков |
| Общие группы и восстановление генов | 45–61; ключевые 50, 53, 54, 56, 57 | Ортология, положение генов, CAGE и KEGG → измеримые общие группы после двух раундов восстановления |
| Матрицы и коэкспрессия | 62–73; ключевые 68, 71/71b, 72 | Согласованные библиотечные матрицы → сети, модули и их сопоставление с массой; отдельные филогенетические проверки |
| Уточнённый OXPHOS и компоненты карт | 74–80 | Повторная проверка 19 исходных генов, фактически измеримый набор16, карты и модули → исправленные суммы и выделенные компоненты |
| Общие регуляторы и промоторы | 81–86; 94/94_monalisa и 98 | Регуляторные области, foreground/background и мотивы → анализы обогащения для групп, в том числе девяти фиксированных наборов |
| Межпанельные и последующие проверки | 87–98 | Птичьи и нептичьи матрицы/группы → последующие сравнения, наклоны, фоны и собственные промоторы эпибласта |

Имена со сходными номерами (`82_…`, `88_…`, `94_…`) — разные существующие реализации/ветви. Они сохранены с исходными именами. `oxphos_thread_lib.py` — общий код; `run_all.sh` и `bg_full_pipeline.sh` — исходные оркестраторы своего исторического контекста, не новый общий вход в этот репозиторий.

## 2. Млекопитающие: фиксированные генные карты

Папка: `analyses/mammal_maps/`.

`00_gene_sets.py` формирует каталоги → `01_sets_mass.py` оценивает суммы и связь с массой → `02_fetch_genomes.sh` и `03_promoters_fimo.py` готовят регуляторный контекст → `04_enrichment_mass.py` и `05_gsea_phylo.py` проверяют мотивы, ранговые/филогенетические сопоставления. `run_all_maps.py` — существующий более широкий скан всех сохранённых карт. Эти две процедуры имеют разные семейства тестов и не должны подменять друг друга.

## 3. Млекопитающие: коэкспрессия

Папка: `analyses/mammal_wgcna/`.

Ветка полной матрицы: `10_prepare_full.py` → `11_wgcna_full.R` → `12_statistics_full.py`. Отдельные сохранённые шаги оценивают leave-one-species устойчивость, чувствительность к дереву и аннотацию модулей. `module_scores.R` — последующая описательная проверка Pearson/BH по уже зафиксированным eigengene, не повторное обнаружение модулей. Из123модулей трёх панелей постер показывает41модуль Ma2016.

## 4. Млекопитающие: pySCENIC

Папка: `analyses/mammal_scenic/`.

`01_prepare.py` → `02_grn.py` → `03_build_db.py` → `04_prune.py` / `04_prune_existing.py` → `05_analyze.py` → `06_verify.R`. `08_stability.py` оценивает сохранённые дополнительные seed. `07_draw.R` и `09_export.py` относятся к отображению/экспорту. Исходные `run_*.sh` сохранены рядом. Неудачные ранние варианты с `failed` в имени исключены из рабочего набора.

## 5. Научные фигуры

В `figures/` находятся существующие R/Python-скрипты панелей, регулонных scatter и теплокарт. README каждой подпапки указывает, из каких сохранённых входов они построены. Это научные панели; редактура финального макета Figma в данный репозиторий не включена.
